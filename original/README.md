# Original MIL-STD-498 Templates

This directory contains the original MIL-STD-498 document templates sourced directly from [kkovacs.eu](http://kkovacs.eu/free-project-management-template-mil-std-498).

## 📁 Directory Structure

- **`original_MIL-STD-498_html/`** - Original HTML templates (22 files)
  - **Source**: [kkovacs.eu](http://kkovacs.eu/free-project-management-template-mil-std-498)
  - **Format**: XHTML 1.0 Transitional
  - **License**: Please refer to kkovacs.eu for licensing information

- **`original_MIL-STD-498_md/`** - Markdown versions (22 files)
  - **Source**: Converted from kkovacs.eu HTML templates using Pandoc
  - **Format**: Markdown
  - **Purpose**: Alternative format for easier editing and processing
